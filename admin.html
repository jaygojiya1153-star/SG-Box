How this works

Your Google Sheet has two tabs: Slots (what's bookable on which date) and Bookings (every confirmed booking). This admin panel reads and writes to both live — no copy-pasting, no GitHub edits needed for day-to-day use.

When a visitor books a slot on the homepage, the system checks the Sheet first — if it's already booked, they're told immediately and shown other options, the same way a movie or bus ticket site works. If it's free, it's booked and marked instantly.

Access code

Change ACCESS_CODE in js/admin-tool.js — and make sure ADMIN_CODE in google-apps-script.gs (inside your Apps Script editor, not GitHub) is updated to match, or slot saves/deletes will be rejected.
